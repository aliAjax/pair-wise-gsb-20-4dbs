# hxwl-06 显微镜玻片借还台

实验室玻片借还登记台：盒位台账、课次预约、归还异常待检与补片闭环。

## 技术栈

React + Vite + TypeScript + CSS（无额外依赖）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106

## 功能

- 玻片台账：每张玻片登记盒位（盒 + 盒内位置）与状态（在盒可约 / 借出中 / 待检）
- 课次预约：学生按课次预约，同一课次同一玻片只留一个借用人；待检玻片不可预约
- 取片与归还：预约转借出；归还时核对实际盒位与盖片，异常须填管理员处理意见并转入待检
- 待检闭环：补片完成后玻片才恢复可约，处理历史留痕
- 整盒余量：按容量与在盒数实时核算
- 持久化：台账保存在浏览器 localStorage，换班、重开页面后待检、借出、余量保持一致

## 代码结构

- `src/data.ts` — 资料：类型、盒位、课次、初始台账
- `src/logic.ts` — 判断：预约/取片/归还/待检/补片等纯函数规则
- `src/storage.ts` — 保存：localStorage 读写与重置
- `src/App.tsx` — 页面：界面渲染与交互
